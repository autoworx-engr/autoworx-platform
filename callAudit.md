# MODULE AUDIT — call (Twilio only)

Scope audited (Infobip skipped per request):

- `src/actions/settings/updateCallForwardingNumber.ts`, `updateCallWhisperEnabled.ts`, `updateMissedCallTextBackEnabled.ts`
- `src/app/api/twilio/**` — route (SMS webhook + credentials GET), incoming, incoming/\_lib/\*, receive, call-status, call-state, call-recording, call-recording/[recordingSid], token, register-voip, whisper, get-phone-number
- `src/app/api/communication/client-hub/get-call-history/route.ts`
- `src/app/(dashboard)/dashboard/communication/client/_component/phone/*` — CallList, CallStatus, IncomingCallAlert, PremiumCallModal, SendCall
- `src/components/CallForwardingSettings.tsx`, `CallWhisperSettings.tsx`, `MissedCallTextBackSettings.tsx`

**Auth note:** Several routes are consumed by both the web dashboard and the autoworx-native mobile app. The unified auth helper [getAuthPrincipal.ts](src/lib/getAuthPrincipal.ts) supports both surfaces (next-auth cookie + Bearer JWT). All "missing auth" fixes below should use `getAuthPrincipal(req)` — that closes the gap for web and mobile in one call. Webhook routes (Twilio callbacks) are a separate category — they need Twilio signature verification, not user auth.

## 2. Top 3 quick wins (<30 min)

1. **Stop leaking Twilio secrets via `GET /api/twilio`** ([src/app/api/twilio/route.ts:180-194](src/app/api/twilio/route.ts#L180-L194)): wrap in `getAuthPrincipal(req)`, scope to `principal.companyId`, and `select` only the fields the client actually needs (drop `apiKeySecret`/`authToken`). Works for both web and mobile.
2. **Fix `isSalesAgent: true` on unknown callers** in both incoming-call routes ([twilio/incoming:96-113](src/app/api/twilio/incoming/route.ts#L96-L113), [twilio/receive:99-108](src/app/api/twilio/receive/route.ts#L99-L108)) — set to `false` or omit. Stops CRM poisoning.
3. **Invoke the dormant guards** in [src/app/api/twilio/token/route.ts:2-7](src/app/api/twilio/token/route.ts#L2-L7) — the imports `assertCompanyAccess` / `requireBillingSession` are already there. Use `getAuthPrincipal(req)` to derive the principal, then call them. One-line change closes the voice-token auth gap.

## 3. Top 3 high-impact refactors

1. **Provider signature verification for all Twilio webhooks.** Today 6 webhooks (`incoming`, `receive`, `call-status`, `call-recording`, `whisper`, SMS POST in `route.ts`) trust the body blindly. Build `verifyTwilioSignature(req)` once and apply to every webhook handler.
2. **Extract `resolveOrCreateClientByPhone(companyId, phone)` and `findTwilioCredentialsByNumber(number)` utilities.** Two files repeat the same broken `contains`-substring lookup + Unknown-Caller create logic. Centralizing eliminates duplicated bugs (substring collisions, `isSalesAgent: true`).
3. **Replace fire-and-forget DB writes / push fan-outs with a job queue (or Next 15 `after()`).** Current pattern in [twilio/incoming/route.ts:128-140](src/app/api/twilio/incoming/route.ts#L128-L140), [twilio/call-status/route.ts:48-51](src/app/api/twilio/call-status/route.ts#L48-L51), and inside `logCallAndNotify` is unsafe on serverless cold-stop and creates O(users) Twilio+DB calls per inbound call.
